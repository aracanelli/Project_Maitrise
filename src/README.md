# Source Layout

Expected modules:

- `screening/`   repository screening and corpus logic
- `parsing/`     Java parsing helpers
- `detection/`   logging statement detection
- `mining/`      Git history traversal
- `matching/`    before/after statement matching
- `dataset/`     schema and serialization
- `features/`    tabular feature extraction
- `graphs/`      graph construction and serialization
- `models/`      baseline and GNN pipelines
- `evaluation/`  metrics, analysis, exports
